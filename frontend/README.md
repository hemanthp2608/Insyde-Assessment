# Insyd Notify — Frontend (React CDN + Babel)

No build step required.

## Run (Option A): Double-click
- Open `index.html` in your browser (Chrome recommended).

## Run (Option B): Serve with Backend
- After starting the backend, you can serve this folder statically (optional).
- Or use an extension like "Live Server" in VS Code.

Update the `API_BASE` in `index.html` if your backend is deployed.
